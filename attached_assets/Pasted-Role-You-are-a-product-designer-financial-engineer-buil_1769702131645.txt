Role: You are a product designer + financial engineer building a multi-property real-estate investor dashboard.
Base currency: USD. Properties are in multiple countries & currencies (Miami, Dubai, Vienna, Alps Chalet, Paris, London).
Goal: Provide an investor-grade portfolio cockpit with fast risk, return, and capital allocation insight.

1. Portfolio Summary View

Design a table or card-grid (Airtable-style) with visual sorting, filtering and color-coded performance.

Each property is one row/card with:

Field	Description
Thumbnail	Small photo of the property
Property Name	Custom name
Country	Location
Current Value (USD)	FX-converted live value
Absolute P/L (USD)	Current value – invested capital
IRR Since Inception	Time-weighted
Financing Structure	e.g. 100% equity, 30% equity / 70% debt
Risk Tag	Low / Medium / High (derived from leverage + FX + vacancy)
Liquidity Tag	Days to exit or % illiquid
Status	Operating / Renovation / For sale

Rows should be color-coded (green → positive, red → negative, amber → watchlist).
Cards should support sparkline mini-charts for value trend.
