KEY WORKFLOW PATTERNS
1. Initial Setup Flow:
Step 1: Import holdings → Section 1
        ↓
Step 2: Classify positions → Section 1
        ↓
Step 3: Set client profile + SAA targets → Section 2
        ↓
Step 4: Configure assumptions → Section 2
        ↓
Step 5: Click "Calculate Risk Metrics" → Section 3 appears
        ↓
Step 6: Review historical → Section 3
        ↓
Step 7: Run stress tests → Section 4
2. Rebalancing Review Flow:
Step 1: Import new holdings → Section 1 updates
        ↓
Step 2: Check drift vs. targets → Section 1 alerts appear
        ↓
Step 3: If drift > tolerance → "Fix in Settings" button
        ↓
Step 4: Adjust SAA (if needed) → Section 2
        ↓
Step 5: Re-run risk calcs → Sections 3 & 4 update
3. Stress Test "What-If" Flow:
Step 1: Run scenario → Section 4
        ↓
Step 2: See poor outcome → "Key Issue" diagnosis
        ↓
Step 3: Click "Review SAA in Settings" → Section 2
        ↓
Step 4: Adjust targets (e.g., Hedges 12% → 15%)
        ↓
Step 5: Save → Triggers re-calc
        ↓
Step 6: Scroll back to Section 4 → See improved scenario outcome

STATE DEPENDENCIES
Section 1 (Portfolio Snapshot):

Always visible
Data source: Holdings CSV upload
Blocks downstream calculations if positions are unclassified

Section 2 (Settings & Assumptions):

Always visible
Independent of Section 1 completion (can set targets before holdings uploaded)
Stores configuration for Sections 3 & 4

Section 3 (Risk Metrics):

Only rendered after:
Section 1: All positions classified
Section 2: SAA targets set
Section 2: Historical NAV data uploaded
User clicks "Calculate Risk Metrics"


Shows loading spinner during calculation (~2-5 seconds)

Section 4 (Stress Testing):

Only rendered after:
Section 3 calculations complete
User clicks "Proceed to Stress Testing" OR scrolls past Section 3


Monte Carlo runs automatically on first view
Scenarios calculated on-demand (when dropdown changes)


ERROR STATES & VALIDATION
Section 1:
⚠ "3 positions need classification" → Blocks risk calculation
⚠ "File parse error: Row 23 missing ISIN" → Shows error banner
✓ "All positions classified" → Enables "Continue to Settings"
Section 2:
⚠ "SAA targets sum to 98%" → Inline validation, red highlight
⚠ "Max drawdown must be negative" → Field validation
⚠ "Historical NAV required for risk analysis" → Blocks Section 3
✓ "Settings saved" → Green toast notification
Section 3:
⏳ "Calculating risk metrics..." → Loading spinner overlay
⚠ "Insufficient data (need 24mo, have 18mo)" → Shows warning, uses available
✓ "Risk metrics updated" → Sections 3 & 4 refresh
Section 4:
⏳ "Running Monte Carlo (10,000 paths)..." → Progress bar
⚠ "Custom scenario: Total must equal 100%" → Modal validation
✓ "Stress test complete" → Results display

Jump links in fixed header (smooth scroll)
Action buttons link sections (e.g., "Fix in Settings ↑" jumps to Section 2)
Progressive disclosure (collapsed details, expand on-demand)
Workflow buttons at section bottoms ("Continue →", "Calculate →")

Section 3 requires explicit "Calculate Risk Metrics" button
Section 4 auto-calculates on first scroll-into-view
Scenario changes recalculate immediately
SAA changes require "Save" + manual re-trigger
