# Documentation Temp Folder

This folder is for draft documentation, planning notes, and temporary documentation work.

## Usage

- Draft documentation before finalizing
- Meeting notes and scratchpads
- Planning documents
- Temporary diagrams and sketches

## Guidelines

- Use descriptive filenames with dates: `phase-3-plan-2025-10-29.md`
- Move finalized docs to parent `docs/` folder
- Clean up regularly - this folder should be ephemeral
- Never commit files from this folder (covered by .gitignore)

This folder is gitignored and will not be tracked in version control.
